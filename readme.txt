WA Sender is a completely FREE extension to connect with your customers by sending bulk messaging for Free.

# Features
---
📢 Unlimited Broadcast Messages.
📎 Unlimited File Attachment.
✏️ Customized Messages.
📝 Add Caption.
🔗 Generate WhatsApp Chat Link.
📤 Send Messages in Batches.
⏳ Reduce time delay & ⏰ Add random delay.
📅 Schedule your campaigns.
📂 Upload numbers from excel files.
👥 Group Export.
⚡ Quick Replies.
📊 Get detailed report of your campaigns.
⏹️ Stop and ▶️ Resume Campaign.
📄 Save Templates.

# Installation

1. Clone the repository:
  ```bash
  git clone https://github.com/jayeshkaithwas/WhatsApp-Web-Extention.git
  ```
2. Open Chrome > Extention > Manage Extention > Turn Developer mode **on** > Load unpacked > Select WhatsApp-Web-Extention folder.
